# 🎓 360° Placement Intelligence Dashboard

A comprehensive Power BI dashboard developed to analyze placement statistics, recruiter insights, salary trends, certifications, and technical skills across Aditya University.

🏆 **Achievement:** Ranked **Top 5 among 126 teams** in the university-level Project Space competition.

---

## 📌 Project Overview

The dashboard provides an end-to-end analysis of placement data for **10,882+ students** from multiple colleges under Aditya University.

It helps placement officers, faculty, and management understand:

- Placement Success Rate
- Company-wise Hiring
- Salary Analysis
- Recruiter Insights
- Branch-wise Placements
- Certification Analytics
- Student Skill Distribution

---

## 🚀 Features

### Student Analysis
- Placement Success Rate
- Average Salary
- College-wise Performance
- Branch-wise Placements
- Placement Trends (2021–2025)

### Company Insights
- Recruiter Statistics
- Maximum & Average CTC
- Company-wise Student Selection
- Salary Category Analysis

### Tech Skills
- Certification Analysis
- Technology-wise Certification Count
- Year-wise Certification Trends
- Skill Distribution
